Финансовый RAG-конвейер

Конвейер RAG для контроля качества финансовых документов (текст + таблицы). Гибридный поиск, контекстное обогащение, переранжирование и оценка на основе LLM для отчетов SEC 10-K и связанных с ними финансовых документов (FinQA, ConvFinQA, TAT-DQA).

Статус: в разработке.

Полная документация (техническое задание, архитектура, спецификация модулей, хронология экспериментов) — в docs/.
